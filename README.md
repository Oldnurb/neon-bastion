# Neon Bastion

Ein kleines, komplett eigenes Browser-Defense-Game ohne Frameworks und ohne externe Assets.

## Spielen

Einfach `index.html` öffnen.

Oder mit GitHub Pages:

1. Neues GitHub Repository erstellen.
2. `index.html`, `styles.css` und `game.js` hochladen.
3. In GitHub: **Settings → Pages**.
4. Unter **Build and deployment**: `Deploy from a branch`.
5. Branch `main`, Ordner `/root` wählen.
6. Speichern. Nach kurzer Zeit ist das Spiel über GitHub Pages erreichbar.

## Gameplay

- Der Core in der Mitte schießt automatisch.
- Gegner kommen von allen Seiten.
- Upgrades sind in Angriff, Verteidigung und Bonus unterteilt.
- Alle 10 Wellen erscheint eine Titan-/Boss-Welle.
- Geschwindigkeit: x1 / x2 / x4.
- Bestwert wird lokal im Browser gespeichert.

## Dateien

- `index.html` – UI und Grundstruktur
- `styles.css` – Neon-Design und Mobile Layout
- `game.js` – Spielmechanik, Gegner, Wellen und Upgrades

## Hinweis

Das Projekt ist absichtlich eigenständig gestaltet und verwendet keine Grafiken, Sounds, Logos oder Quellcodes aus einem bestehenden Spiel.
